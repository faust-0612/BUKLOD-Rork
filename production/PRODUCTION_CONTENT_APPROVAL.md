# Production Content Approval

Staging contains pilot/devotional/learning/help content that was useful for testing.

Before copying any of it into production, review:

## Devotionals
- theological accuracy
- Scripture references
- spelling/grammar
- intended publication dates
- discussion questions
- prayer wording
- no staging-only language unless intentionally retained

## Learning tracks
- New Believer Foundations
- Membership Course
- any mentor-reviewed assignment
- quiz answers
- certificate criteria

## Help Center
Verify that help copy matches the final tested app:
- reflection privacy
- prayer privacy
- account deletion
- notifications
- offline behavior
- data rights
- leader follow-up

## Announcement templates
Remove or rewrite:
- "pilot"
- "test data"
- staging-only instructions

## Production rule
Do not copy a staging row merely because it exists.
Every production content set needs an explicit content owner/reviewer.
