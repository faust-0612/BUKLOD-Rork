# BUKLOD Empire visual direction — stylized benchmark v1
Decision: stop treating increased polygon count, texture resolution or procedural detail as evidence of improved art. Use the current gameplay foundation and evaluate the rendered game at gameplay camera scale. The owner reference is a stylized top-down fantasy game screenshot: clear ground, recognizable silhouettes, limited palette, atmospheric foliage and restrained effects. Do not copy its assets or branding.

## Locked approach
- One benchmark: Phan in the existing Genesis Rift offline match, with existing minions, tower and Groundbreaker. Use the playable scene and real input, not a promotional image or an isolated mannequin. Full roster remains in the source; no new hero production until the first benchmark demonstrates a coherent visual style.
- Orthographic 55-degree camera, 8.5-unit vertical half-size, stable heading and damped follow; target 10–15% screen height for a hero, measure on a real capture before locking scale. No spectacle zoom or camera shake by default.
- Palette: warm golden key, cool blue/gray fill, green/gold Lux and red/dark Tenebra accents. Use subdued ground and foliage, strong actor silhouettes, matte surfaces, restrained metal, no distracting full-screen bloom or dense particle noise. Retain existing art candidates initially; replace poor assets individually only after identifying why they fail.
- Motion: read actual displayed horizontal displacement; damp locomotion parameter. Check grounded footfalls, idle/walk/run transitions, directional turning, one readable attack anticipation/contact/recovery, and one recognizable Groundbreaker. No extra particles as a substitute for pose quality.
- Environment: use the current map and terrain alignment; evaluate one lane first. Keep route edges recognizable and silhouettes visible. Use coherent simple trees, rocks and plants, not random geometric detail. Change art only, never pathfinding or combat balance.
- Capture at 16:9 gameplay framing (1280x720 minimum): idle, movement, minion encounter, tower and skill. Record a short real gameplay clip. Compare with the owner's quality expectation: readable, cohesive, smooth and appealing. Do not claim an art pass without actual evidence.
- Zero purchases. Reuse current rights-cleared assets, or use documented free original assets with license evidence. No cloud generation/paid build without authorization. Retain existing production catalog gates. No MAIN changes.

## Executable review
Run the existing asset preparation and consolidated offline review assembly in the pinned editor. Then select BUKLOD Empire / Visual benchmark / Assemble Phan stylized review. A separate ignored scene StylizedPhanBenchmark.unity is created; original scene and build settings remain untouched. In Play mode select Phan and start a normal training match; use the real controls. Evaluate the lane, enemy units, tower and Groundbreaker. This is a review-only look test, not the full APK. The existing production guard remains authoritative.

## Gate
Do not expand this preset to the roster, rebuild the game around another engine or claim visual readiness based on source checks. Actual rendered evidence and a side-by-side art review are still required for visual acceptance. If the owner defers actual verification, continue independent nonvisual development but leave this visual gate unverified. The initial camera, grade and movement values are proposals subject to actual rendered evidence; the new look is not yet a demonstrated improvement.
