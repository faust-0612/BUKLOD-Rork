# Visual control editor
Open MENU > HUD > DRAG EDITOR. The editor overlays the paused battle, displays all nine actual control positions/sizes, supports direct drag, individual size changes, reset and done. Position commits only on release; overlapping changes rejected. Device-local preferences survive match restarts and app restarts. Safe area changes trigger layout refresh. Existing directional placement controls remain as an alternative. Current zoom is button-based, not pinch. Fullscreen preference uses Unity's API; Android immersive behavior and touch interaction still need actual device validation. This is source implementation, not verified visual or compilation acceptance.
