# Arena interaction and display completion extension
Reuse the existing mobile input, HUD, menu and camera. Local-device persistent customization: move/attack/three skills/tactic/recall/minion/tower individually adjustable with directional controls and size increments, bounded safe area and overlap checks; reset default, zoom in/out during gameplay, fullscreen preference, detailed/minimal optional information (minimap/objective). Essential HP/mana, action controls and cooldown remain visible. Keep screen top reserved for menu/zoom and information. No combat balance or authority changes. No promise of Android immersive mode beyond Unity Screen.fullScreen API; OS behavior requires device check. Future work: drag-and-drop editor with live preview, pinch zoom if gesture ownership can be isolated, opacity/accessibility profiles, user-facing asset icons/audio, expanded info overlays and authored entrance doors. These changes do not imply that those future items are finished. Source code only; Unity and mobile interaction tests not executed.
