## Asset sources and usage
Primary: Quaternius CC0 Standard. Source lock pins a public mirror commit and exact pack trees; official creator pages establish provenance. Use Universal Base Characters + Modular Fantasy outfits and Universal Animation Library for humanoids; reserve Ultimate Modular Men for compatible NPC/placeholder evaluations, not automatic rig compatibility. Stylized Nature for foliage; Medieval Village for modular buildings; Fantasy Props for gear, farming and mines; Ultimate Animated Animals and Cute/Ultimate Monsters for neutral entities. Standard is a subset, not the paid Source edition. Existing shaders are not included merely because the models are free.
Secondary: KayKit free CC0 editions, only if the primary benchmark fails; keep a separate consistent style test, never mix random proportions. Unity Chop Chop architecture and Unity Fantasy Kingdom lighting are references, not imported production asset packs. Do not copy Synty or unverified assets.
## Build path
1. Seed: three authored plant models (geometry plus textures) and two embedded animated creature models, copied byte-identically to review-only Assets/ThirdParty/QuaterniusReview. Seed lock records each Git blob. No production provenance claim.
2. Acquisition: python Tools/acquire-authored-assets.py --verify-seed verifies committed files. Without flag, fetch the eight pinned mirror pack trees to ignored ReviewOutput; use --pack to select. No credentials or paid tools; cache, bounded retries, hash checks, per-pack receipt. External sources not in the mirror remain listed as pending, not downloaded.
3. Integrate nature in separate Phan stylized scene: no colliders or navigation changes. Use actual materials and authored meshes, not remeshed primitives. Creature candidates contain Idle/Walk/Bite/Death/Hit clips; map only after comparing canonical species/roles.
4. Build first actual Phan authored body: inspect matching base/outfit skeleton, skin weights, bind poses and Unity Avatar. Retarget authored idle/walk/run/attack; use bespoke Groundbreaker timing where needed. Preserve Phan green/gold, heavy Earthforge silhouette, stone and weapon. Do not use an unrelated farmer or ranger as final Phan. For all 13, keep distinct body/armor/weapon silhouette and canonical skill IDs.
5. Environment: replace existing visual props by compatible authored prefab at canonical positions; no change to pathfinding/cover/resources/visibility. For buildings assemble modular walls, roof, tower and faction accent on canonical footprint; maintain separate 8 structure types per faction. Village and mine visuals remain tied to simulation.
6. Validate playable benchmark at actual orthographic gameplay scale: recognizable Phan, footfall, combat, minions, foliage, tower, frame pacing, consistent lighting. Only expand after actual acceptance; owner can defer testing, not declare a visual pass. Keep original source catalog and guard. APK requires Unity compilation and artifact verification; online readiness remains independent.
