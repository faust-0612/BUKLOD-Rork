# Authored interaction assets
Ten original files are vendored with byte-identical Git blob hashes from pinned sources in AUTHORED_INTERACTION_ASSETS.json (five PNG sprites, one OGG click, one self-contained GLB doorway and three license texts). Kenney and KayKit official pages declare CC0; the mobile controls mirror has no pack-specific license file, so retain the official page as evidence. The review composer imports Kenney sprites and sounds and binds them to the actual touch HUD and menu. The KayKit doorway has a separate authored leaf node and embedded texture. It opens as the initialized match is revealed; decorative, no pathfinding or victory change. Review assets are fenced from normal production scenes/catalogs. No Unity compile, device test, visual approval, or live deployment performed.
