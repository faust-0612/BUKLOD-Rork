# Original procedural review pipeline (zero paid asset generation)
This is a separate art review, not a release. Run `python Tools/prepare-review-assets.py` from the Unity project or any working directory; it regenerates the 13 original rigged heroes and verifies/extracts 22 faction GLBs from the committed two ZIP packs. It needs only Python standard library. Then invoke `Buklod.Empire.Editor.CandidateReviewComposer.Prepare` from the Unity Editor menu or a licensed batch-mode Editor. glTFast imports native prefabs/clips; the composer creates isolated review prefabs, controllers and a gallery scene under git-ignored Assets/Generated/ReviewOnly. It never changes EditorBuildSettings, application ID, production catalog or approval receipts. The actual Unity import path is source-ready and has not been executed in this session; missing clips/import errors deliberately stop it. Review the map separately via its prefab. Candidate clip motions and likeness need visual review and refinement; this is not a gameplay or premium quality acceptance. No cloud builds initiated.

Hero candidate generation and binary validation were executed in a temporary Python environment using the exact Git blobs a48580dad0b48da9d6eba242d227b526073cb13e (generator), 6213d13ffca6ce281cc20abcdd8384809f699339 (review refinement), c1293c5b60b1e89c0f5567e777d5503c6e901788 (SacredStones). Results: 13 models, 49,784 triangles, 234 bones, 117 animation clips, 8,434,028 GLB bytes; validated buffer bounds, indices, joint indices, normalized skin weights, animation times/quaternions, Sacred Stone identities. A software geometry preview confirmed the candidates are low-poly, not approved premium likenesses. Faction packs contain 22 models and 132 clips with binary/skin/animation checks; visual deformation remains unverified. Production guard remains unchanged. The hero binary files were generated locally, not uploaded to the repository; the existing deterministic generator recreates them.

## Skill motion revision
The current generator produces 12 clips per hero (156 total), including three independent Primary/Secondary/Ultimate motion curves per hero matched to all 39 canonical skill IDs. The old ultimate is preserved as LegacyUltimate for review. The Unity candidate controller now uses distinct slot clips and loops locomotion; it no longer aliases both skills to Skill. These are procedural choreography candidates, not approved character likeness or verified in-engine animation. Offline execution of the revised generator (same numerical profiles and motion code) checked 13 GLBs, 87,084 triangles, 39 distinct skill motion signatures, 130 embedded PNGs, finite UVs, normalized skin weights/quaternions, valid indices and keyframe times. No Unity compilation or production changes.

Run `python Tools/test_validate_skill_motions.py` after generating the hero review files. The preparation script now runs the standard-library motion verifier before faction extraction. It rejects bad hashes, invalid rotation data, incorrect canonical slot assignments, missing joint tracks and duplicated active motions. Evidence is recorded in `Tools/skill-motion-evidence.json`. This is an offline gate only; it does not certify Unity Animator playback or art quality.

## Offline match review (Editor only)
After assigning a valid URP pipeline and running the existing asset generation and candidate import, invoke `Buklod.Empire.Editor.OfflineReviewComposer.Prepare`. This creates a separate ignored scene with the actual offline simulation, hero and faction prefabs, camera, HUD, lighting and combat pulses. It corrects the imported map's X-axis conversion, uses explicit positive-scale navigation proxies matching the canonical cover and lane coordinates, and checks complete routes plus hero spawn navigation. This does not establish detailed terrain collision parity. It never sets build scenes, app ID or provenance. The Android guard rejects any enabled scene that references generated review assets. The review authorization path is compiled only in the Unity Editor. Actual Editor import/play and rendering are still unverified. No cloud builds or subscriptions are required for source preparation.

## Cosmetic review
`python Tools/variant_review.py` creates three palette candidates per canonical hero (Original, Radiant, Nightwatch; provisional names). It changes only armor, trim, fabric and leather base-color factors; original geometry, skeletal rig, embedded texture bytes, animation channels and Sacred Stone materials remain unchanged. The existing prepare-review-assets.py calls it automatically. An optional two-argument ZIP input/output mode supports offline review without Unity. The 39 generated GLBs are review assets, not 39 independent meshes or approved premium designs. The separate `BUKLOD Empire/Assemble cosmetic review gallery` menu verifies all file hashes, imports prefabs and saves an ignored review-only scene. Android build protection remains unchanged. No player unlocks, entitlement changes or economy changes. Offline archive execution validated all 39 GLBs and ZIP CRC/hash integrity; actual Unity import/rendering remains untested.
