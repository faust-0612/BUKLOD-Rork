# Native scene assembly status
The runtime source now contains the 13 canonical hero kits, 39 skill dispatch rules, fixed-step offline 5v5 battle, core protection, minion waves, bot movement/retreat, native input and a rendering/HUD adapter. It is not a completed or compiled game. Village scene effects, full passive parity, VFX/SFX, hero selection/variants and device acceptance remain open.
Required authoring inputs: `Assets/Production/VisualCatalog.asset` referencing a licensed Genesis Rift prefab (world coordinates x=0..320, z=0..220), two faction tower/core and five role prefabs per faction, thirteen distinct rigged hero prefabs and provenance receipt. The approved original visuals must be checked separately; runtime validation of distinct meshes is not proof of likeness. Configure an actual URP asset and input handling (new Input System or both). Run the Editor menu `BUKLOD Empire/Assemble approved battle scene` or the cloud pre-export method `Buklod.Empire.Editor.ArenaSceneComposer.PrepareCloud` only after those assets exist. The composer bakes NavMesh, creates the scene, and sets isolated Android settings. The existing build guard still rejects missing scenes/wrong app ID. Do not start a cloud build at this source checkpoint.
