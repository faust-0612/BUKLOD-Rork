# Skill presentation revision
39 canonical skill IDs map to ten bounded caster-local geometry cue families and 39 distinct original synthesized mono PCM sounds. The sound bank is committed, regenerated offline with Node, and requires no licensed samples or paid service. The existing owner audio collection has not been substituted or cleared; rights and quality review remain pending. These are illustrative cast cues, not authoritative target or radius visualization. Existing rules and damage are unchanged. Last successful cast aim is recorded for visual direction only. Audio playback is capped at eight spatial voices, distant bots are suppressed, and the existing 24-line pool is reused. Offline bank generation checked deterministic bytes, per-cue peak/envelope, unique PCM segments and exact header/length; Unity tests were authored but not run. Actual rendering/listening and final character likeness remain open. No build or release authorized by this revision.

Successful casts now record a bounded eight-event sequence per hero, preventing same-tick casts from overwriting audio/VFX observations. Full-body Animator selects the latest cast when several arrive in the same frame; a simultaneous hit cannot override it. The added NUnit tests cover same-tick casts, rejected casts and history eviction. Unity test execution is still pending.
