# BUKLOD Empire Unity migration — isolated DEV
Baseline 094a6e6600002842fe869eecb05703e080926e56. Offline only. No production/staging, Supabase, Expo, Vercel or online economy changes.
This is an initial source migration, not a completed premium game. Run `python3 apps/buklod-empire-unity/Tools/intake.py` from a clean repository checkout with Python/Pillow, then open this folder in Unity 6 LTS. The existing original procedural hero generator is reused for baseline GLBs; these are explicitly not approved-art likeness models. Do not distribute without individual visual verification and Unity/Android tests.
References are copied losslessly into ReferenceArt outside Assets, with a Git blob integrity check. Existing C# match rules port is limited to directional targeting, retreat, core protection, shop and match time; the full canonical skills, villagers, minions, scene integration, input and animation retargeting are still required. Original GDScript remains the reference.
Asset production: use the exact portrait and motion sources in ReferenceIndex.json; preserve canonical IDs (ellusur = ELESUR). Produce separate rigged, textured hero meshes; faction minion and villager art must be identified and separately linked before generation. Maps must be modeled as playable terrain, not a flat illustration. Do not use prototype geometry as final approved assets. Existing private library packs must be reconciled and licensed before use.
No APK or OTA until Unity imports and all 13 unique meshes, distinct animations, faction assets, actual game scenes and Android play tests pass. Offline results cannot award persistent points or settle online rewards.
