# BUKLOD Empire Unity migration — isolated DEV
Baseline 094a6e6600002842fe869eecb05703e080926e56. Offline only. No production/staging, Supabase, Expo, Vercel or online economy changes.
This is an initial source migration, not a completed premium game. Run `python3 apps/buklod-empire-unity/Tools/intake.py` from a clean repository checkout with Python/Pillow, then open this folder in Unity 6 LTS. The existing original procedural hero generator is reused for baseline GLBs; these are explicitly not approved-art likeness models. Do not distribute without individual visual verification and Unity/Android tests.
References are copied losslessly into ReferenceArt outside Assets, with a Git blob integrity check. Native C# source includes 13 hero kits, 39 active skill dispatches, a fixed-step offline match, minion waves, village simulation, touch input, HUD and NavMesh/scene adapters. Full passive parity, premium visual and animation integration, hero selection/variants, VFX/SFX and actual Unity/Android acceptance remain open. Original GDScript remains the reference.
Asset production: use the exact portrait and motion sources in ReferenceIndex.json; preserve canonical IDs (ellusur = ELESUR). Produce separate rigged, textured hero meshes; faction minion and villager art must be identified and separately linked before generation. Maps must be modeled as playable terrain, not a flat illustration. Do not use prototype geometry as final approved assets. Existing private library packs must be reconciled and licensed before use.
Do not trigger a cloud build until approved assets, scene assembly and project settings are ready. A development APK is for actual device acceptance; no final distribution or OTA until Unity import, compilation, gameplay, visuals and Android acceptance pass. Offline results cannot award persistent points or settle online rewards.

Sacred stones: `Assets/Resources/SacredStones.json` is the single source of cosmetic hero stone identities, joined by canonical hero ID via `SacredStoneCatalog.TryGet`. The first twelve follow Revelation 21:19–20 (NIV); Trudice's Diamond and all virtues/palettes are original BUKLOD lore. Integrate the stone into approved art as an emblem or accessory without changing existing roles, skills, XP, rank or economy. The asset production queue references this catalog. Final 3D and HUD integration still require Unity acceptance.
