# BUKLOD Empire — separate native Android DEV app
Package org.mzbministry.buklod.empire. Uses official Godot 4.7.2 AAR with native Android Gradle only. The APK contains the canonical Godot game project as root Android assets (no startup pack overrides). Carries the reviewed 13 heroes, 52 pose atlases, 70 sound cues, 42 Kingdom class artworks, 22 public CC0 models including 2 rigs, Arena combat and Kingdom, House, Community scenes. No React Native/Expo/MAIN bundle. 3D is still an exploration preview, not a completed ranked 3D game.
DEV signing uses the runner's debug key; not a durable release signature. No production deployment, OTA, or change to MAIN.

## Reward and account boundary
No isolated Supabase project. The existing BUKLOD MAIN project remains the sole authority for auth, character identity/level, Circle Rank, BP, QMP, inventory, collectibles, diamonds, property and ranked settlement. This first installable offline DEV APK contains no account credentials and grants no real rewards. Existing special-character unlocks and reward eligibility are NOT inferred from local gameplay. Before introducing online rewards, integrate normal Supabase Auth against the same project, account-scoped read-only existing RPCs, and only audited server-authoritative match/reward endpoints with replay protection and verified settlement. Do not import unauthenticated local progress or copy the MAIN ledger. MAIN game removal is a separate step after verified Empire readiness and account/reward parity.
