# BUKLOD Genesis — Unified Native World Foundation

One embedded Godot 4.7.2 AAR and one deterministic signed APK asset pack serve
four guarded features: Arena, Kingdom, Personal Community and Personal House/Lot.

**Status:** DEV native-world visual preview foundation, NOT full playable Kingdom,
property purchase, live village simulation, or finished 39-scene RPG. Original
Arena remains an offline Godot practice simulation. All server-ledger writes,
BP/Character Diamonds, property rights, materials, and ranks remain in verified
BUKLOD backend APIs and are intentionally not touched by native preview.

The three world previews reuse approved Genesis world source WebP art and
existing estate WAV cues, 1–10 construction progression previews with five
visible stages, 13 Kingdom station markers, 10 animated community avatars,
basic quality 30/60 FPS cap, and a Back To BUKLOD exit.

The Android bridge passes a strictly whitelisted world name via an in-app,
non-exported Activity. No remote PCK execution, extra app install, new
permission, foreground service, or server-generated reward trust.

**Still blocking EAS-signed functional staging:** exact Godot gameplay parity
(13 heroes, movement, NPC/tower/item combat, all assets/effects), scene-entry
physical device proof, Android audio focus with calls and AdMob, release
signature identity, source QA (Arena LOS/blockers), isolated World/SOS backend,
and new native RC source parity. No production/Play/OTA release.
