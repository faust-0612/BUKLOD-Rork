# BUKLOD Empire — first independent Android APK

Package org.mzbministry.buklod.empire. Official Godot Android export; no Expo, React Native, EAS or Vercel. Independent of MAIN and installed Genesis staging. Canonical consolidated 206 content: 7da090dfc73429ff7a1080d74249ae38c1067fbf; public 22 CC0 GLBs (2 animated rigs), 13 arena heroes, 70 existing cues, 42 Kingdom cosmetics. No private vendor assets, no arbitrary remote packs. Kingdom world and Arena practice are native scenes, not ranked multiplayer.

Phase 1 is offline installable preview, no Internet permission or Supabase credentials. No client-generated BUKLOD BP/QMP, experience, ranks, collectibles, payouts or property claims. No new Supabase project. MAIN game routes, assets and production untouched until verified standalone replacement.

Phase 2 (not activated): same authoritative existing Supabase auth/identity and reward ledger; use dedicated Empire client identity/session authorization, server-validated outcomes with idempotency, replay/anti-farming checks, canonical account ownership, atomic settlement, and cross-app reconciliation. Client practice must not mint transferable rewards. Never fork user balances or copy auth tokens through untrusted links. Remove MAIN assets/routes only after verified migration and rollback/compatibility gate.

Internal signing uses a temporary debug certificate; this APK is for standalone first install only. Stable dedicated signing key needed before distributing updates. Desktop/headless tests are not Android device verification. A release receipt must distinguish binary build and actual device QA.
