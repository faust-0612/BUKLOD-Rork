# BUKLOD Season 2 — 40 approved Circle Rank visual assets / avatar placement
Owner approval: 2026-11-19 (Manila). Scope: staging-only design integration. **No change to Season 1 rank logic, BP, QMP, payouts or rank thresholds.**

- SOURCE: User's **Buklod rank badges** folder, two full sheets. Exactly eight families × five ranks (V, IV, III, II, I). Individual transparent PNG cutouts and a 40-up QA contact sheet are retained as delivery artifacts. For runtime memory/network economy the 40 alpha-cut cells are packed in `assets/season2/buklod-circle-ranks-40.webp`; this is fully bundled offline.
- `manifest.json` documents each of the 40 rank-to-grid coordinates. Each badge is clipped **only to its own transparent 160x160 cell**, never shown with a black or white square; no neighbor badge is present in a cell.
- One shared `ProfileAvatar` renders the badge at 10 o'clock (upper-left), with a proportional larger overlay and rank-family colored photo border. Blue dot at 6 o'clock displays **only while an authenticated Realtime session is confirmed in foreground**; missing/disconnected presence means no online claim. Existing Notes remain separate at right/bottom and must not overlap.
- All `BuklodTappableAvatar` and `ConnectTappableAvatar` instances inherit this, including Wall post authors/comments, Connect inbox contacts/chat, profile and member lists. Parent overflow was changed from hidden to visible to prevent clipping without changing circle tap hit-tests.
- Rank lookup first uses existing verified rank supplied by Wall/Connect; other avatars use one viewer-scoped, bounded batched `get_member_circle_ranks_v1` RPC, with 90s cache / 30s failure backoff and no invented ranks on weak signals. Server results are ignored after viewer-account switch.
- Circle Rank Progression (all 40), recognition and points rank card use the same approved art through the existing `BuklodCircleRankBadge`. Locked ranks are dimmed without changing earned status.
- **Release order** DEV source QA → manual native appearance + strict AdMob/instant navigation tests → verified staging-user OTA, no Season2 production before Dec 6 or separate owner promotion approval. This commit/PR is NOT itself a published OTA.
